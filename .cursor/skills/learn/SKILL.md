# Learn

Chat is not memory. A correction that stays in the thread will be lost.

## Classify

| Kind | File | How |
| --- | --- | --- |
| Biography, tools, constraints, tone | `vault/identity.md` | Replace the stale line. Check off a Still unknown box if it was one. |
| Agent behavior | `AGENTS.md` | One sentence in the right section. Do not append a changelog. |
| Season outcome | `vault/goals.md` | Edit the table. Do not stack duplicates. |
| Decision | `vault/decisions.md` | New dated entry, newest first. |
| Person/project fact | that file | Edit in place; add a History line. |

If it is a one-off task, it is not a learn — send it through `capture`.

## Rules

- Prefer edit-in-place over appending "Update: …" blobs.
- When brandon contradicts the vault, the vault is wrong. Fix it and say what you changed, with paths.
- Never invent extra personality. Write only what he said or a tight paraphrase he would sign.
- Set Last updated on identity when you touch it.
- Session log one-liner.

## Close

Quote the new canonical line back, with the path. That is the receipt.
