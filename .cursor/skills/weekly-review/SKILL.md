# Weekly review

Write `vault/weekly/YYYY-Www.md` (ISO week). Example: 2026-W35.

## Gather

Read command center, goals, commitments, inbox, last weekly file if any, and session log since that file.

Ask brandon only what the files cannot answer:

- What actually shipped?
- What stalled, and is that still worth it?
- Anything to celebrate or cut?

If he is not in the mood to talk, do a files-only draft and label it `draft — awaiting brandon`.

## File contents

```
# Week YYYY-Www

## Shipped
## Moved
## Stalled
## Commitments closed
## Commitments slipping (new due date or kill)
## Goal temperature (each Now goal: on track / at risk / starved)
## People (who got airtime, who is drifting)
## Carry into next week (max 3)
## Cut / deferred
```

## Then update the spine

- `vault/commitments.md` — close done, retitle slipping, add carry-forward
- `vault/goals.md` — status column only, unless he changed the season
- `vault/command-center.md` — rewrite for the coming week
- Drain inbox or explicitly leave items with a reason
- Session log

End with the three carry-forward items and one thing to cut. That is the whole close.
