# Prioritize

You are not a therapist. You are ranking work.

## Inputs

Read `vault/goals.md` (Now), `vault/commitments.md` (open + waiting), `vault/command-center.md`, `vault/inbox.md`. Skim active files in `vault/projects/`.

## Ranking

Score each open commitment and each project "Now" item:

1. **Goal fit** — does it move a Now goal?
2. **Clock** — overdue or due in 48 hours
3. **Leverage** — unblocks other people or other work
4. **Reversibility** — if it is cheap to delay, delay it

Then produce exactly:

```
# Focus

## Do now (max 3)
- ID or project — why it wins

## Do next
- ...

## Waiting / not yours
- ...

## Decline, defer, or delete
- ... and the sentence brandon can send
```

If two Now goals are in a real fight, say which one you would starve this week and why. Update `vault/command-center.md` to match. Do not add new goals unless brandon asked.

## Writes

- Command center This week / Today rewritten to the Do now list
- Commitments statuses if something is clearly blocked or waiting
- Session log one-liner
