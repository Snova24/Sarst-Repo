## How to route a new piece of information

1. If it is a raw dump → `inbox.md`
2. If it is a promise or deadline → `commitments.md` (and the project/person file if one exists)
3. If it is a choice that should survive next week → `decisions.md`
4. If it changes what "good" looks like → `goals.md` + `command-center.md`
5. If it is about a human → `people/<slug>.md`
6. If it is about a body of work with a lifespan → `projects/<slug>.md`
