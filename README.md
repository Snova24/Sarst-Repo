# Clipbook

A Sunday circular you actually keep. Browse deals, copy codes, clip them into a wallet, and see what you still stand to save.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

```bash
npm test          # domain tests
npm run build     # production bundle
```

## What it is

No accounts. Wallet lives in the browser (`localStorage` key `clipbook.wallet.v1`). Catalog is fictional merchants — Harbor Pantry, Willow Table, and the rest — not scraped store codes.
